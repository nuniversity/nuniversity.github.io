# Accessibility (axe)

`makeAxeBuilder()` is provided by the E2E fixture and uses WCAG 2.0/2.1 A + AA
tags. The covered surfaces live in
`tests/e2e/integration/accessibility.spec.ts`:

- `/en/` — home
- `/en/courses/` — hub
- one lesson
- mixed practice
- language course overview
- quiz hub

## Policy

- Fail on **serious** and **critical** violations.
- Keep the surface list in sync with the product; do not delete a surface to go
  green.
- Fix the UI, not the audit. Past fixes: `role="region"` on focusable scrollers,
  accessible names containing visible text, contrast for badges/callouts.
- Do not use `AxeBuilder.disableRules()` to bypass a product issue. If a rule is a
  known false positive, document it here and narrow the exclusion to the exact
  selector in the spec.
- Attach the raw axe JSON to the report on failure for triage.

## Adding a surface

1. Add the path to `SURFACES` with a concise name.
2. Run only the accessibility spec.
3. Inspect the attached JSON.
4. Fix implementation code; rerun.
5. Keep serious/critical at zero.
