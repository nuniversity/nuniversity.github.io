# Advanced Skill Example

This skill demonstrates advanced patterns and features.

---

## Activation Context

Activate when the user requests advanced skill examples or complex workflow patterns.

---

## Instructions

### Phase 1: Analysis

1. **Understand Requirements**
   - Analyze the user's request
   - Identify constraints and requirements
   - Determine output format

2. **Plan Workflow**
   - Break down complex tasks into steps
   - Identify dependencies between steps
   - Estimate time and resources

### Phase 2: Execution

1. **Generate Content**
   - Follow established conventions
   - Use consistent formatting
   - Validate output at each step

2. **Quality Assurance**
   - Run validation scripts
   - Check for errors and warnings
   - Verify output matches requirements

### Phase 3: Integration

1. **Save Results**
   - Save to appropriate location
   - Update metadata if needed
   - Log changes for audit

2. **Report Status**
   - Provide summary of changes
   - List any warnings or issues
   - Suggest next steps

---

## Output Format

### Required Fields

- title: The title of the content
- description: A brief description
- status: The current status

### Optional Fields

- tags: List of tags for categorization
- metadata: Additional metadata

---

## Quality Rules

- Rule 1: All content must be valid Markdown
- Rule 2: Titles must be unique
- Rule 3: Descriptions must be concise
- Rule 4: Status must be one of: draft, review, published
- Rule 5: Tags must be lowercase and hyphenated
