## Alternatives rejected

- **flexsearch/pagefind/fuse** — new deps for a ~600-entry corpus; hand-rolled matcher + fetch-on-open index is smaller and locale-explicit (D57).
- **Dictionary imported client-side for search** — 181 KB inline; build-time JSON fetch keeps first load light (D57).
- **Sanitize after rehype-katex** — would require allowlisting KaTeX's full span/style soup; before-katex keeps the schema small (D58).
- **Per-widget `onResult` props** — 5 dispatch sites + prop drilling; context with no-op default is transparent to widget reuse (D56).
- **Dedicated /profile page** — new route/sitemap/verify surface for v1; header chip+popover satisfies acceptance (D60).
- **Auto-complete lesson on visit** — no learning signal; explicit CTA keeps % meaningful (D54).
- **New `content/languages/tracks/` type** — rejected at program level (D67, Phase 9): tracks = regular courses.
