## Course Description

Introduction to programming using Python. This course connects fundamental programming concepts to **web development, data science, automation, and problem-solving**. Students will learn through **interactive coding exercises, real-world projects, and hands-on practice**.

### Learning Outcomes

Upon completing this course, students will be able to:
1. Write Python programs from scratch
2. Use variables, data types, and operators
3. Implement control flow (if/else, loops)
4. Define and use functions
5. Work with lists, dictionaries, and files

---

## Real-World Examples

### Web Development

**Example 1: Website Backend**
Python powers Instagram, Pinterest, and Reddit. When you like a post, Python code runs on the server to update the database and send notifications.

**Example 2: Web Scraping**
Python can automatically collect data from websites. Real estate agents use scrapers to monitor property prices, and researchers use them to gather scientific data.

### Data Science

**Example 3: Netflix Recommendations**
Netflix uses Python to analyze your viewing history and recommend movies. The algorithm considers: what you watched, when you watched it, and what similar users liked.

**Example 4: Financial Analysis**
Wall Street uses Python to analyze stock markets. Algorithms can process millions of transactions per second, detecting patterns humans would miss.

### Automation

**Example 5: Email Automation**
Python can send personalized emails to thousands of people. Businesses use this for marketing campaigns and notifications.

**Example 6: File Organization**
Python can automatically sort files into folders based on type, date, or name. This saves hours of manual work.

### Artificial Intelligence

**Example 7: Chatbots**
AI assistants like Siri and Alexa use Python for natural language processing. They understand your questions and generate responses.

**Example 8: Image Recognition**
Python libraries can identify objects in photos. This technology powers self-driving cars and medical image analysis.

## Story: The Accidental Language

> **Hook**: "Python was named after Monty Python, not the snake. And it was created as a hobby project that became the world's most popular programming language."

> **Story**: In 1989, Guido van Rossum was looking for a Christmas project. He wanted a language that was easy to read and fun to use. He named it after Monty Python's Flying Circus - and Python became the language that powers Google, Netflix, and NASA.

> **Connection**: Python's simplicity makes it perfect for beginners. The same language that powers complex AI systems can also help you automate your homework.

## Lesson Structure

### Lesson 01: What is Programming?

**Duration:** 45 minutes

**Hook**: "Programming is giving instructions to a computer. It's like writing a recipe, but the computer follows every instruction exactly."

**Story**: "Ada Lovelace wrote the first computer program in 1843 - for a machine that was never built. She predicted that computers could do more than just calculate, envisioning them creating music and art."

**Learning Objectives:**
- Understand what programming is
- Learn how computers execute instructions
- Write your first Python program
- Understand syntax and errors

**Content Outline:**

#### 1. What is Programming? (10 min)
- Instructions for computers
- Programming languages
- Why Python?

#### 2. Your First Program (10 min)
- print("Hello, World!")
- Running Python code
- The Python interpreter

#### 3. Syntax and Errors (10 min)
- Indentation
- Common errors
- Reading error messages

#### 4. Interactive Elements (15 min)
- **Code Runner**: Write and execute Python code
- **Error Debugger**: Find and fix bugs
- **Program Builder**: Drag-and-drop to build programs

**Real-World Application**: Automating a simple task

**Practice Problems:**
1. Write a program that prints your name.
2. Write a program that prints "1 + 1 =" followed by the result.
3. What happens if you forget a closing parenthesis?
4. Write a program that prints your favorite quote.
5. Run the program: print(2 * 3 + 4)

### Lesson 02: Variables and Data Types

**Duration:** 50 minutes

**Hook**: "Variables are like labeled boxes - they store data that your program can use and change."

**Story": "In the 1950s, programming meant plugging cables into massive computers. Variables were physical switches. Today, variables are symbolic, but the concept is the same: store and retrieve information."

**Learning Objectives:**
- Understand variables and assignment
- Learn Python data types (int, float, string, bool)
- Convert between data types
- Use string operations

**Real-World Applications:**
- **Data Processing**: Storing and manipulating data
- **Web Development**: User information, form data
- **Science**: Experimental data, calculations
- **Everyday**: Contact lists, budgets

**Practice Problems:**
1. Create variables for your name, age, and favorite color.
2. What is the type of: 42, 3.14, "hello", True?
3. Convert the string "123" to an integer.
4. Write a program that calculates your age in 10 years.
5. Create a string that combines first and last name.

---

### Lesson 03: Operators

**Duration:** 55 minutes

**Hook**: "Operators are the verbs of programming - they make things happen."

**Story**: "The first programming languages had only a handful of operators. Modern Python has dozens, but the basic ones (+, -, *, /) are universal across almost all languages."

**Learning Objectives:**
- Use arithmetic operators
- Apply comparison operators
- Understand logical operators
- Combine operators in expressions

**Real-World Applications:**
- **Calculations**: Financial, scientific, engineering
- **Decision Making**: Comparing values
- **Data Processing**: Filtering, searching
- **Game Development**: Score calculations

**Practice Problems:**
1. Calculate: 15 % 4, 15 // 4, 2 ** 3
2. What is the result of: 10 > 5 and 3 < 7?
3. Write an expression that checks if a number is even.
4. Calculate the area of a circle with radius 5.
5. What is the order of operations in Python?

---

### Lesson 04: Control Flow - If/Else

**Duration:** 60 minutes

**Hook": "If/else statements let your program make decisions - just like humans do every day."

**Story**: "The first computer program to make decisions was written in 1843 by Ada Lovelace. She envisioned a machine that could choose between different calculations based on conditions."

**Learning Objectives:**
- Write if statements
- Use if-else and if-elif-else
- Understand boolean logic
- Apply conditional logic to problems

**Real-World Applications:**
- **Web Development**: User authentication, form validation
- **Game Development**: Win/lose conditions
- **Data Processing**: Filtering data
- **Everyday**: Automatic doors, traffic lights

**Practice Problems:**
1. Write a program that prints "even" or "odd" for a given number.
2. Create a grade calculator (A, B, C, D, F based on score).
3. Write a program that finds the largest of three numbers.
4. Create a simple calculator that performs +, -, *, / based on input.
5. Write a program that checks if a year is a leap year.

---

### Lesson 05: Control Flow - Loops

**Duration:** 65 minutes

**Hook**: "Loops let your computer do repetitive tasks - something humans find boring but computers do perfectly."

**Story": "The first looms (for weaving fabric) used punch cards to repeat patterns. In the 1800s, Charles Babbage designed a computer that used the same concept. Loops are one of the oldest programming ideas."

**Learning Objectives:**
- Write for loops
- Use while loops
- Understand loop control (break, continue)
- Apply loops to solve problems

**Real-World Applications:**
- **Data Processing**: Iterating through records
- **Web Development**: Generating HTML, processing forms
- **Scientific Computing**: Simulations, calculations
- **Automation**: Repetitive tasks

**Practice Problems:**
1. Write a program that prints numbers 1 to 10.
2. Calculate the sum of numbers from 1 to 100.
3. Write a program that prints the multiplication table for 5.
4. Find all even numbers between 1 and 50.
5. Write a program that counts down from 10 to 1, then prints "Liftoff!"

### Lesson 06: Functions

**Duration:** 70 minutes

**Hook**: "Functions are reusable blocks of code. Write once, use many times."

**Story**: "The concept of functions comes from mathematics, but in programming, functions can do anything: calculate, search, create, or even control robots."

**Learning Objectives:**
- Define and call functions
- Use parameters and return values
- Understand scope
- Write modular code

**Real-World Applications:**
- **Code Organization**: Breaking large programs into parts
- **Reusability**: Sharing code across projects
- **Libraries**: Using pre-built functions
- **APIs**: Interacting with web services

**Practice Problems:**
1. Write a function that calculates the area of a rectangle.
2. Create a function that converts Celsius to Fahrenheit.
3. Write a function that checks if a number is prime.
4. Create a function that generates a random password.
5. Write a function that takes a list and returns the average.

### Lesson 07: Lists

**Duration:** 65 minutes

**Hook**: "Lists are Python's way of storing collections of data - like a shopping list or a playlist."

**Story**: "Before computers, data was stored in filing cabinets. Lists are digital filing cabinets - but much faster and more powerful."

**Learning Objectives:**
- Create and access lists
- Modify lists (append, insert, remove)
- Slice lists
- Use list methods

**Real-World Applications:**
- **Data Processing**: Storing records, filtering data
- **Web Development**: User lists, product catalogs
- **Scientific Computing**: Data arrays, measurements
- **Everyday**: Shopping lists, to-do lists

**Practice Problems:**
1. Create a list of your 5 favorite movies.
2. Add a movie to the beginning of the list.
3. Remove a movie from the list.
4. Find the longest string in a list.
5. Create a list of numbers and sort them.

### Lesson 08: Dictionaries

**Duration:** 65 minutes

**Hook**: "Dictionaries store data in key-value pairs - like a real dictionary maps words to definitions."

**Story**: "The first electronic dictionary was created in 1960. Python dictionaries work the same way: you look up a key to find its value."

**Learning Objectives:**
- Create and access dictionaries
- Modify dictionaries
- Use dictionary methods
- Apply dictionaries to real problems

**Real-World Applications:**
- **Web Development**: JSON data, user profiles
- **Data Processing**: Database records, configuration
- **Scientific Computing**: Named data, metadata
- **Everyday**: Contact lists, recipes

**Practice Problems:**
1. Create a dictionary with 3 students and their grades.
2. Add a new student to the dictionary.
3. Find the average grade.
4. Create a word frequency counter from a sentence.
5. Invert a dictionary (swap keys and values).

**Duration:** 70 minutes

**Hook**: "Files let your programs save and load data - like saving a game or reading a document."

**Story": "In the early days of computing, data was stored on punch cards. Today, files can be on your computer, in the cloud, or on a server across the world."

**Learning Objectives:**
- Read text files
- Write to text files
- Process CSV files
- Handle file errors

**Real-World Applications:**
- **Data Processing**: Reading datasets, generating reports
- **Web Development**: Configuration files, logs
- **Scientific Computing**: Experimental data
- **Everyday**: Documents, spreadsheets

**Practice Problems:**
1. Write a program that reads a file and counts the words.
2. Create a program that writes a shopping list to a file.
3. Read a CSV file of student grades and calculate the average.
4. Create a program that copies a file.
5. Write a program that searches for a word in a file.
